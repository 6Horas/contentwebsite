# contentwebsite

Repositório público de arquivos estáticos usados pelo site `nyx-site`.

## CDN

Os arquivos podem ser acessados pelo jsDelivr mantendo o caminho existente:

```text
https://cdn.jsdelivr.net/gh/6Horas/contentwebsite@main/<caminho-do-arquivo>
```

Exemplo:

```text
https://cdn.jsdelivr.net/gh/6Horas/contentwebsite@main/deadlock/hero-renders/<arquivo>
```

As pastas `Sounds` e `dl_render` já existentes foram preservadas. Os diretórios
`deadlock`, `steam`, `video` e `Casamento-Wishlist` refletem os arquivos públicos
atuais do projeto `nyx-site`.
